## Process

Define one useful deliverable, exclusions, dependencies and acceptance evidence. Inspect code before calling a feature absent. Label proposals and uncertainties. Keep assignments within ownership. Make the scope available for human steering while continuing authorized work.

## Outputs

Update [local-mvp-scope.md](output/local-mvp-scope.md), or name a new scope for a later milestone. Update progress. Promote enduring intent changes to the product reference instead of duplicating it.
