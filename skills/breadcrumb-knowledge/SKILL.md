# Maintain Breadcrumb knowledge

Resolve paths from the project containing `AGENTS.md`; when opened through a discovery symlink, use canonical `skills/breadcrumb-knowledge/`.

Read [the index](../../knowledge/CONTEXT.md) and [working method](../../knowledge/working-method.md), then the relevant topic and current output. For status, read `PROGRESS.md` and inspect its evidence.

Locate the canonical claim. Separate intent, implementation, validation and unverified assertions. Record source/date/status. Resolve contradictions explicitly; a plan or generated response is not a tested fact.

Update a reference when an enduring decision changes. Put run results in the relevant stage output and next actions in progress. Mark dependent outputs stale after input changes. Preserve original kit files.

Validate changed links and report meaningful gaps. Do not bulk-read unrelated folders, build a second memory database or persist secrets. This organizes development knowledge; runtime route data changes require a task that actually calls for them.
