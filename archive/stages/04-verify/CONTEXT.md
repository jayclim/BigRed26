## Process

Run meaningful checks, then exercise the changed journey. Record commands, outcomes, environment and limits. Visual claims need rendered inspection. Distinguish mock passes from live recognition and browser simulation from phone evidence. Fix or return observed failures; never invent a pass.

## Outputs

Write [verification.md](output/verification.md) and useful screenshots. Mark gates passed, failed or not run. Update progress and outstanding build gaps. Change scope explicitly rather than quietly weakening a check.
