# Task routing

Choose the smallest relevant stage. A scoped bug fix can enter build/verify directly.

| Task | Read next |
|---|---|
| Understand the product, change scope, assign teammates | [01-scope](stages/01-scope/CONTEXT.md) |
| Design or refine a screen or interaction | [02-design](stages/02-design/CONTEXT.md) |
| Implement or fix application/API/provider code | [03-build](stages/03-build/CONTEXT.md) |
| Test the app, inspect mobile layouts, assess demo readiness | [04-verify](stages/04-verify/CONTEXT.md) |
| Add evidence, reconcile decisions, update memory | [breadcrumb-knowledge](skills/breadcrumb-knowledge/SKILL.md) |
| Check status or resume | [PROGRESS.md](PROGRESS.md), then the active stage |
| Coordinate agents, PRs or overnight work | [Work protocol](knowledge/work-protocol.md), [run setup](docs/OVERNIGHT.md) |

For a particular fact, use [knowledge/CONTEXT.md](knowledge/CONTEXT.md). The kit is source material; maintained references describe current decisions. Actual behavior is established by code and observed checks.
